# Expense App MVP

## Goal

Allow employees to:

1. Take a photo of a receipt
2. Extract amount, date and vendor using OCR
3. Classify the expense
4. Store expenses locally
5. Generate monthly expense claim PDF
6. Sign the PDF
7. Send the PDF to manager by email

## Employee Setup

- Full Name
- Email
- Manager Email

## Expense Fields

- Receipt Image
- Date
- Vendor
- Amount
- Category
- Description

## Expense Categories

- Travel
- Meals
- Fuel
- Office Supplies
- Hosting
- Other

## Reports

- Monthly PDF
- Attach all receipts
- Fill company expense form

## Approval

- Send PDF to manager via email
- No workflow in MVP
