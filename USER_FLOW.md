# User Flow

## First Time Setup

User enters:

- Full Name
- Email
- Manager Email

Save

---

## Add Expense

Take receipt photo

Run OCR

Extract:

- Vendor
- Date
- Amount

User reviews information

User selects:

- Category

Optional:

- Description
- Car Number
- Guests

Save expense

---

## Monthly Report

User clicks Generate Report

System:

- Collects all monthly expenses
- Calculates totals
- Fills expense claim form
- Attaches receipt images

---

## Signature

User signs report

System embeds signature into PDF

---

## Manager

User clicks Send To Manager

System opens email:

- To: Manager Email
- Subject: Expense Claim
- Attachment: PDF
